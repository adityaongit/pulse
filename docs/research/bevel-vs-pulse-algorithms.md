# Bevel algorithms compared with Pulse

> Superseded by docs/research/bevel/ (2026-10-08). Where this file conflicts, the new docs win.

Updated 2026-10-06. Independently audited against the supplied Bevel 3.1.7 (2728) IPA and Pulse HEAD `6efe9df65ed2891ac9e14aed8493dc508a6401f2`. [Full audit and equations](bevel-metrics.md), [machine inventory](bevel-metric-inventory.json), [verification report](bevel-audit.json). No Pulse app algorithms changed.

Bevel's Fitbit Air path is present in this IPA, including Google sync, explicit `hrvRmssd` mapping and an Air heart-rate-sharing guide. The user's reported Bevel outputs are the parity target. Pulse's connector retains daily HRV but omits the sample HRV stream, sample SpO2 and sleep short awakenings. Missing-data branches can still produce scores. Calling all unavailable optional inputs an Air blocker was too strong.

Counts use one distinct score, balance, load, estimate or recommendation family, with daily/workout aliases, age submodels, contributors and internal helpers collapsed. **18 discovered families; 12 existing Pulse counterparts/benchmark targets; 11 mapped-core candidates plus one partial Biological Age composite; two new cardio-only leads; four additional-input families.** Zero new Air-compatible families proven end to end, zero runtime-validated replicas, zero production replacements justified. The 1208 rows in 173 ledger groups, including 172 Swift registries and one manually named Derived group are a field/case ledger, not metric counts. Full strength and optional age data gaps overlap these categories rather than increasing the total.
