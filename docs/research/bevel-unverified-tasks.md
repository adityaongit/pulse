# Unverified findings and research tasks

> Superseded by docs/research/bevel/ (2026-10-08). Where this file conflicts, the new docs win.

Updated 2026-10-06. Consolidated from the [metric inventory](bevel-metric-inventory.json), [verified tables](bevel-verified-tables.json), [audit](bevel-audit.json) and [research](bevel-metrics.md). [Machine task list](bevel-unverified-tasks.json).

This is every currently recorded gap for the 18 audited families, plus shared discovery and validation work. It does not claim all possible IPA logic has been discovered. Already recovered formulas, default configuration, population SD, sample selector branches, automatic-goal kernel, Target Strain range and Energy update clipping are not being reopened as unknown.

A complete static replica requires the formula, required inputs or derivations, and surrounding preprocessing/history/state/presentation. Runtime parity is a separate axis. An unavailable Pulse mapping is a known connector gap; Air-specific availability is a separate question. A metadata-only field is not a recovered algorithm or a new score.

There are **104 grouped tasks**: 16 shared, 66 metric-specific, four shared runtime tasks and 18 family fixture suites containing 96 recorded reference-case entries. Shared tasks overlap metric tasks, so these counts are not independent blocker counts.

## Completion rule

- Static task: record caller/producer addresses, exact branches/constants/units, source/window/state behavior, evidence filename and corrected inventory status. Record unresolved boundaries explicitly.
- Input task: establish supplied or correctly derivable inputs and their device provenance, source, units, cadence and history. Do not substitute a Classic-derived input without verifying equivalence.
- Connector gap: document the exact missing retained fields and proposed retention/derivation; implement only under a later implementation task.
- Runtime task: pin the build and complete same-input reference comparisons, including intermediates and null/calibration/display behavior. Record tolerances and failed cases.
