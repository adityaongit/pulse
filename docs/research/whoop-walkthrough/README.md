# WHOOP walkthrough screenshots

Phone screenshots of the WHOOP app, used as UI reference for the clone pass (see `../whoop-ui-gaps/`). Each file is named `<area>-<feature>-<detail>.png`: the app area, the component or screen it shows, then the visible state or range (week, month, 6m, scrolled, empty, saved). A `-2` or `-3` suffix marks another shot of the same feature in the same state.
